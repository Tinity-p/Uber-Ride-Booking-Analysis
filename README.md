# Uber Ride Booking Analysis

## Project Overview
This project analyses Uber ride booking data to understand booking trends, ride completion, cancellations, vehicle usage, payment methods, and customer and driver ratings.

## Tools Used
- **SQL (MySQL):** Data querying and analysis
- **Python:** Data cleaning and data analysis using Pandas
- **Power BI:** Interactive dashboard and visualisation

## Key Performance Indicators (KPIs)
- Total Bookings: 150,000
- Completed Rides: 93,000
- Cancellation Rate: 25%
- Total Booking Value: 51.85M
- Average Ride Distance: 24.64
- Average Driver Rating: 4.23

## Dashboard Features
- Booking Status Analysis
- Vehicle Type Analysis
- Top 5 Pickup Locations
- Monthly Booking Trend
- Payment Method Analysis
- Driver Ratings Distribution
- Recent Bookings Table
- Interactive Vehicle Type and Booking Status filters

## Key Insights
- The dataset contains 150,000 bookings.
- July recorded the highest number of bookings, with 12,897.
- 93,000 rides were completed, representing a 62% completion rate.
- Auto was the most-used vehicle type by booking count.
- Khandas was the top pickup location by booking count.
- The average driver rating was 4.23.

This project demonstrates the use of SQL, Python, and Power BI to analyse ride booking data and present useful business insights through an interactive dashboard.
